# Приложение для заполнения стоматологических карт

## Назначение

Браузерное приложение, которое помогает врачу оформить стоматологическую карту по единому шаблону и подготовить PDF для печати по утверждённой форме.

## Основной процесс

1. Выбрать пациента и тип приёма.
2. Отметить жалобы, результаты осмотра, диагноз и лечение.
3. Автоматически сформировать текст медицинской карты.
4. Подготовить PDF для скачивания или печати.
5. Сохранить карту в истории пациента.

## Первая версия

- Типы приёмов: терапия, первичный осмотр, цифровая ортопедия.
- Четыре врача с отдельными учётными записями.
- Руководитель с доступом для контроля записей.
- Электронная подпись врача не требуется.
- Функции: карты, PDF, история пациента.

## Следующие этапы

- Исправление записей с журналом изменений.
- Статистические формы.
- Списание материалов.
- Подготовка к использованию несколькими независимыми клиниками.

## Технологический выбор

- Интерфейс: React и Next.js.
- Сервер: Python и FastAPI.
- База данных: PostgreSQL.
- Платформа: браузер на компьютере или планшете.

## Стратегия вывода

1. Запуск для всех врачей «ЛК Дент».
2. Доработка расширенных функций.
3. Бесплатный двухнедельный пилот в первой внешней клинике.
4. Продажа другим небольшим клиникам.

## Риски

- Перегрузка первой версии функциями. Решение: первый запуск ограничен картами, PDF и историей.
- Необходимость точно воспроизвести утверждённую медицинскую форму Республики Беларусь.
- При продаже другим клиникам потребуется надёжное разделение данных, прав доступа, резервных копий и настроек.

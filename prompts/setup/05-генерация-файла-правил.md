# Генерация файла правил

## Зачем

У агента должен быть один файл, где записано, как с вами работать: кто вы, чего хотите, что можно и что нельзя, как оформлять результат. Этот файл агент читает перед каждой задачей. Без него приходится повторять одни и те же требования снова и снова, а агент всё равно про них забывает между сессиями.

Файл правил обычно называется `CLAUDE.md` или `AGENTS.md` (имя зависит от инструмента). Это просто текст на человеческом языке - не программа.

## Когда применять

Один раз, когда база знаний уже собрана (см. промпт про интервью). Правила опираются на неё.

## Как сгенерировать

Вставьте запрос:

```
Собери мне файл правил для работы над этим проектом (CLAUDE.md). Возьми за основу шаблон из папки templates/, а фактуру - из базы знаний в .business/.

Требования к файлу:
- Пиши на русском, простым языком, без жаргона - я не программист.
- Не раздувай: держи файл в пределах 200 строк. Лучше коротко и по делу, чем длинно и «на всякий случай».
- Обязательно оставь два правила и не выкидывай их:
  1. Для каждой крупной задачи сначала пишется план в папку plans/.
  2. В конце каждой сессии пишется короткое ретро (разбор: что сделали, что дальше).
- Включи: кто я и чем занимаюсь, как со мной общаться, что согласовывать до выполнения, где лежит база знаний, правила по безопасности и секретам.
- Покажи готовый файл целиком и объясни в двух словах, что где.
```

## Что делать с результатом

- Прочитайте файл глазами. Он должен быть понятен вам самому - если что-то непонятно, попросите переписать проще.
- Проверьте, что на месте оба обязательных правила (план и ретро) - без них теряется дисциплина работы.
- Если файл получился длиннее 200 строк - скажите «сократи, оставь только важное». Раздутый файл правил агент читает хуже.
- Со временем дополняйте файл: заметили, что агент повторяет ошибку - добавьте правило, чтобы не повторял.

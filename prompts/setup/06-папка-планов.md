# Папка планов

## Зачем

Крупную задачу нельзя бросать агенту одним махом - он может уйти не туда, и вы это заметите, только когда всё уже сделано неправильно. План решает это: агент сначала описывает, что и в каком порядке собирается делать, вы это читаете и одобряете, и только потом начинается работа. План также хранит историю - через месяц можно вспомнить, зачем и что делали.

Все планы лежат в одной папке `plans/`, каждый план - отдельный файл. Внутри плана задачи разбиты на шаги, у каждого шага стоит отметка: `[ ]` - не сделано, `[x]` - сделано.

## Когда применять

Один раз при настройке создаётся сама папка и заготовки. Дальше на каждую крупную задачу заводится новый файл плана.

## Как настроить

Вставьте запрос:

```
Создай папку plans/ для моих планов. Внутри положи два файла:

1. README.md - короткое пояснение по-русски: зачем нужна эта папка, что один план = один файл, как называть файлы (по дате и теме, например 2026-07-01-название-задачи.md), что значат отметки [ ] и [x].

2. ШАБЛОН-ПЛАНА.md - пустой образец плана, который я буду копировать под новые задачи. В шаблоне должны быть разделы:
- Задача (что и зачем делаем, в двух-трёх фразах).
- Шаги (список пунктов с отметками [ ], которые агент отмечает [x] по мере готовности).
- Итог (заполняется в конце: что получилось, что осталось, на что обратить внимание).

Пиши простым языком. Покажи оба файла.
```

## Что делать с результатом

- Загляните в `plans/`: там должны появиться `README.md` и `ШАБЛОН-ПЛАНА.md`.
- Прочитайте шаблон - он должен быть понятен без объяснений.
- Дальше при большой задаче говорите агенту: «сначала напиши план по шаблону в plans/, я проверю, потом начнёшь». Не разрешайте пропускать этот шаг на серьёзных делах.

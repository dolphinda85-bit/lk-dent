# Стартер-комплект: работа с AI-агентом

Готовый набор для учеников - скопируйте эту папку в свой новый проект и запускайте. Внутри всё, чтобы агент (Claude Code, Codex или совместимый) с первого дня работал системно.

> **С чего начать - файл `00-НАЧНИ-ОТСЮДА.md`.** Там три шага запуска и инструкция для самого агента.

## Что внутри

- **`00-НАЧНИ-ОТСЮДА.md`** - точка входа: как запустить и что сделает агент.
- **`МЕТОДОЛОГИЯ-работы-с-AI-агентом.md`** - принципы системной работы с агентом (читалка).
- **`ОНБОРДИНГ.md`** - сценарий, по которому агент сам настраивает проект за 10 шагов.
- **`AUTOPILOT.md`** - флаг настройки (переключатель онбординга); пока `completed: false`, агент ведёт настройку.
- **`prompts/`** - библиотека готовых промптов под типовые задачи:
  - `setup/` - настройка среды (голосовой ввод, звук, защита, интервью базы знаний, генерация правил, планы, тест-цикл, навыки, браузер);
  - `launch/` - вывод в продакшн (репозиторий, деплой, приём платежей);
  - `methodology/` - приёмы (стресс-тест, критика плана, планирование недели, импорт проекта).
  - Начинайте с `prompts/INDEX.md` - таблица «надо X → возьми Y».
- **`templates/`** - образцы файлов: правила (`AGENTS.md.tmpl` / `CLAUDE.md.tmpl`), план, ретро, звук+защита, настройка автономности Codex, структура базы знаний.

## С чего начать

1. Скопируйте содержимое папки в свой проект.
2. Откройте его в редакторе и напишите агенту: «Прочитай `00-НАЧНИ-ОТСЮДА.md` и начни онбординг» - он пойдёт по `ОНБОРДИНГ.md`.
3. Дальше работайте по методичке (`МЕТОДОЛОГИЯ-работы-с-AI-агентом.md`).

## Главные принципы (одной страницей)

- **Знания** о проекте - в `.business/`, **правила** для агента - в файле правил, **память** - в планах и ретро.
- Один чат - одна задача. Большая задача - через план. В конце сессии - ретро и бэкап.
- Перед промптом с нуля - загляни в `prompts/INDEX.md`.
- Перед крупным шагом - стресс-тест «что пойдёт не так».
- Секреты - только в защищённом хранилище, не в коде и не в репозитории.

## Текущий рабочий модуль ЛК Дент

В репозитории зафиксирована основа будущего модуля формирования стоматологических карт по диктовке:

- `source/DentProtocol_BY_MASTER_PROMPT_v6.0.md` - проверенная версия клинической логики;
- `schemas/medical-card-043u.schema.json` - машинная структура электронной карты;
- `docs/STRUCTURE_043U.md` - описание структуры и движения данных;
- `docs/PDF_MAPPING_043U_V6.md` - координатная привязка данных к форме 043/у;
- `scripts/fill_043u_pdf.py` - тестовый генератор заполненной формы;
- `examples/test-case-001.json` - обезличенный тестовый ортопедический случай;
- `output/pdf/Форма_043у_тест_001.pdf` - проверенный результат заполнения.

Рабочая последовательность: короткая диктовка врача -> структурированные данные -> текст карты -> проверка врачом -> PDF установленной формы -> сохранение в истории пациента.

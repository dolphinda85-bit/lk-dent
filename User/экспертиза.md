# Экспертиза

- 20 лет стоматологической практики.
- Цифровая ортопедия.
- Управление клиникой.
- Контроль медицинской документации.
- Обучение врачей.

Хорошее решение оценивается по безопасности пациента, удобству врача, соблюдению законодательства, скорости работы, экономической эффективности, простоте внедрения и качеству медицинской документации.

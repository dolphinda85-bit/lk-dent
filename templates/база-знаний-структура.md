# Структура базы знаний (.business/)

Скрытая папка со знаниями о проекте. Агент читает `INDEX.md` первым, потом только нужный файл (экономит контекст). Заполняется через интервью (см. `prompts/setup/04-интервью-база-знаний.md`).

```
.business/
├── INDEX.md          ← оглавление «надо X → файл Y»
├── company/          ← кто вы, формат, ценности
├── products/         ← что продаёте и по какой цене
├── audience/         ← кто клиенты, их возражения, путь
├── goals/            ← цели: год / квартал / месяц, метрики
├── economics/        ← экономика: выручка, расходы, прогноз
├── marketing/        ← каналы, воронка, конкуренты
├── assets/           ← гайдлайны бренда, отзывы
└── execution/        ← операционка:
    ├── СОСТОЯНИЕ-ПРОЕКТА.md   ← снимок «где мы сейчас» (читать первым в сессии)
    ├── backlog.md            ← бэклог задач
    └── ГГГГ-WНН.md           ← план недели
```

Минимальный `INDEX.md`:
```
# База знаний - оглавление
| Надо | Файл |
|---|---|
| Кто мы, формат, ценности | company/ |
| Продукты и цены | products/ |
| Клиенты и возражения | audience/ |
| Цели и метрики | goals/ |
| Экономика | economics/ |
| Каналы и воронка | marketing/ |
| Бренд, отзывы | assets/ |
| Текущее состояние | execution/СОСТОЯНИЕ-ПРОЕКТА.md |
```
